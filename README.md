# Aeroplanes Map Project (Курсовая работа)

Проект представляет собой консольное приложение для получения и фильтрации данных о самолетах, находящихся в воздушном пространстве выбранной страны.

## Функционал
- Интеграция с внешними API (`nominatim.openstreetmap.org` и `opensky-network.org`).
- Получение координат страны (boundingbox) и поиск самолетов в этой зоне.
- Преобразование сырых данных в список объектов класса `Aeroplane`.
- Вывод Топ N самолетов по высоте полета.
- Фильтрация самолетов по высоте и стране регистрации.
- Сохранение, удаление и чтение данных о самолетах в JSON-файл.
- Обработка исключений при работе с сетью и неверным вводом.
